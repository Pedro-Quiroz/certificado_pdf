# Generador de Certificados en PDF

Este proyecto permite generar certificados personalizados en formato PDF utilizando Python y la librería ReportLab.

## 📄 Descripción

El script genera un archivo PDF que incluye:

- Imagen de fondo del certificado
- Nombre del estudiante
- Nombre del curso
- Fecha de aprobación
- Cantidad de horas
- Enlace personalizado (con QR)
- Fuentes personalizadas (OpenSans)

## 🧱 Requisitos

- Python 3.x
- Entorno virtual (opcional pero recomendado)

### Dependencias (se instalan desde `requirements.txt`):

- reportlab
- qrcode
- Pillow
